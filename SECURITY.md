# Security Policy

## Reporting Security Issues

If you discover a security vulnerability in this project, please email the maintainers directly rather than using the public issue tracker. This allows us to assess the risk, fix the issue, and release patches before the vulnerability is disclosed publicly.

**Do not open public issues for security vulnerabilities.**

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| Latest  | ✅ Actively maintained |
| Older   | ⚠️ Bug fixes only   |

## Security Considerations

### Known Limitations
- This is an educational simulator, not intended for production use
- The simulator runs untrusted code in its execution environment
- Memory isolation is not enforced in the same way as real operating systems

### Best Practices
- Always update to the latest version
- Review untrusted program files before running them in the simulator
- Do not use this simulator for security-critical applications
- Keep Java and JavaFX updated

## Dependencies

The project has minimal external dependencies:
- **Java Runtime**: 11 or higher
- **JavaFX SDK**: 17 or higher

No third-party libraries are bundled with the core application.

## Updates and Patches

Security updates will be released as needed. Users are encouraged to:
1. Watch the repository for releases
2. Update to latest versions promptly
3. Report any security concerns immediately
